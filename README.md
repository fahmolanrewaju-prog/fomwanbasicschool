### 📂 How to Upload to GitHub

1. Create a new repository on GitHub (e.g. `fomwan-basic-school`)
2. Upload all the files and folders in this directory
3. Enable **GitHub Pages**:
   - Go to Settings → Pages
   - Source: Deploy from a branch
   - Branch: `main` (or `master`) → `/ (root)`
4. Your site will be live at:  
   `https://yourusername.github.io/fomwan-basic-school/`

You can also host it on Netlify, Vercel, or any free static hosting.
